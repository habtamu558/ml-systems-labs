\## Environment



\* Python 3.11.8

\* NumPy 1.26.4

\* pandas 2.2.2

\* scikit-learn 1.5.0

\* PyTorch 2.3.1

\* MLflow 2.14.1



The complete list of required packages and pinned versions is available in `requirements.txt`.



\## Lab 1



Lab 1 covers:



\* Environment and dependency verification

\* Breast cancer dataset preparation

\* Logistic Regression baseline

\* Random Forest baseline

\* Accuracy evaluation

\* Training-time measurement

\* Inference-latency measurement

\* Model-size measurement

\* Memory measurement

\* Deployment resource-budget analysis



Results and measurements are stored in:



```text

lab01/results/

```



The Lab 1 report is available at:



```text

lab01/report.md

```



\## Reproducibility



The experiments use fixed random seeds (`42`) where applicable to make the results reproducible.
